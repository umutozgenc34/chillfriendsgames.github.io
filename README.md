# chillfriendsgames.com

Chill Friends Games web sitesi. GitHub Pages üzerinde yayınlanır, derleme adımı yoktur.

- `index.html` salon sahnesi: kartuşu konsola sürükle, TV oyunu anlatsın
- `oyunlar.html`, `hakkimizda.html`, `iletisim.html`, `404.html`
- Oyun bilgileri tek yerde: `js/data.js`
- Arayüz metinleri (TR / EN): `js/i18n.js`

Yeni oyun eklemek için `js/data.js` içine bir kayıt, `img/` içine 320x320 bir ikon, `index.html` içine bir `.cart` butonu ve `js/salon.js` içindeki `HOMES` listesine raftaki yerini eklemek yeterli.
